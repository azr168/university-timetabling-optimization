# Genetic algorithm in solving university timetabling problem

This project automates the complex and tedious process of generating 
conflict-free academic schedules for university administrators and faculty members.

## Problem statement
University administrators and faculty schedulers face significant challenges 
when building academic timetables manually due to the vast number of lectures, rooms, 
and complex constraints. This manual process is incredibly tedious, time-consuming, 
and prone to human error, often resulting in double-booked rooms, overlapping student 
classes, or lecturer schedule conflicts. Consequently, these inefficiencies waste valuable 
administrative effort, reduce resource utilization, and disrupt the academic experience for 
both students and teaching staff.
