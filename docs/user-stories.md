# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a faculty administrator, I want to import course, room, and lecturer details into the 
system, so that I can set up all necessary inputs for schedule generation quickly without 
manual data entry errors.
2. As a timetable scheduler, I want to execute the Genetic Algorithm solver with configurable 
constraint rules, so that I can automatically generate an optimized, conflict-free timetable 
in minutes.
3. As a department scheduler, I want to visually inspect and export the generated timetable 
into PDF or CSV format, so that I can verify schedule quality and distribute it to teaching 
staff and students.
